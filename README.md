# FunityArcade (Pure HTML)

A single-file offline mini-arcade to kill boredom. Open `index.html` and enjoy:

- 🧠 Memory Match
- ⚡ Reaction Timer
- 🎨 Doodle Canvas
- 🌬️ Breathing Pacer
- ❓ Trivia Quiz (10 Q)
- 🐹 Whack-a-Mole (30s)

No installs. No internet. No tracking.

## How to run (Windows)

1. Open the folder in Explorer: `c:\Users\AbhijitVibhute\Desktop\Timepass`.
2. Double-click `index.html` to open it in your default browser.

Or from PowerShell:

```powershell
# Open in default browser
Start-Process "c:\Users\AbhijitVibhute\Desktop\Timepass\index.html"
```

## Tips

- Click 🎲 Random for a surprise game.
- Use 🌙 Dark to switch themes; your choice is remembered.
- Doodle Canvas works with mouse and touch; use Save PNG to export your artwork.

## Notes

- Everything is client-side and offline. No external libraries.
- Works best in a modern browser (Edge, Chrome, Firefox). Mobile-friendly.

Enjoy! 🎯
